<h1>Galeri WebP</h1>

<p>
  <strong>Galeri WebP</strong>, Android cihazlarda görselleri kolayca
  <strong>WebP formatına dönüştürmek</strong> ve dosya boyutunu küçültmek için
  geliştirilmiş pratik bir mobil uygulamadır.
</p>

<p>
  Uygulama; özellikle haber sitesi yöneticileri, WordPress kullanıcıları,
  sosyal medya içerik üreticileri ve görsellerini daha hafif hale getirmek
  isteyen herkes için hazırlanmıştır.
</p>

<hr>

<h2>Özellikler</h2>

<ul>
  <li>JPG, PNG ve benzeri görselleri WebP formatına dönüştürme</li>
  <li>Birden fazla görsel seçme desteği</li>
  <li>Kalite ayarı ile görsel boyutunu küçültme</li>
  <li>Görsel ölçeklendirme desteği</li>
  <li>Varsayılan dosya adı belirleme</li>
  <li>Otomatik sıralı dosya adlandırma</li>
  <li>Dönüştürülen görselleri galeriye kaydetme</li>
  <li>Basit ve kullanımı kolay arayüz</li>
</ul>

<hr>

<h2>Dosya Adlandırma</h2>

<p>
  Uygulama içinde varsayılan görsel adı belirlenebilir.
</p>

<p>Örneğin varsayılan ad olarak:</p>

<pre><code>dugunfoto</code></pre>

<p>yazıldığında dönüştürülen görseller şu şekilde adlandırılır:</p>

<pre><code>dugunfoto001.webp
dugunfoto002.webp
dugunfoto003.webp</code></pre>

<p>
  Bu özellik özellikle haber siteleri, ürün galerileri ve toplu görsel
  yüklemeleri için kolaylık sağlar.
</p>

<hr>

<h2>Kullanım Alanları</h2>

<ul>
  <li>Haber siteleri için görsel hazırlama</li>
  <li>WordPress medya yüklemeleri</li>
  <li>Sosyal medya görsellerini optimize etme</li>
  <li>Galeri fotoğraflarını WebP formatına dönüştürme</li>
  <li>Mobil cihazda görsel dosya boyutlarını küçültme</li>
  <li>İnternet sitelerinde daha hızlı yüklenen görseller hazırlama</li>
</ul>

<h2>English Summary</h2>

<p>
  <strong>Galeri WebP</strong> is a simple Android application for converting
  images to WebP format and reducing file size. It supports multiple image
  selection, quality optimization, custom default file names and automatic
  numbered file naming.
</p>
